结局媒体来源说明

本游戏结局采用《崩坏3》原作影像片段、角色中文原声及音乐《Elysian Realm》（HOYO-MiX / 李敬浩，收录于原声专辑 ELYSIUM）。原作媒体版权归其权利人；公开分发授权尚未核验。

胜利结尾使用爱莉希雅在原作第 31 章“此即乐园”的四句连续原声，按原顺序播放，未拼字、改词或生成配音；画面采用原作夜景和《因你而在的故事》花田片段。夜景源文件没有音轨；花田片段的原混合音轨已移除，尚未找到独立原作音效音轨。

最终 Boss 失败界面的两句错误输入反馈使用侵蚀之律者原作中文原声。删除阶段及正确输入后的反馈分别采用《崩坏3》动画短片《因你而在的故事》中侵蚀之律者和爱莉希雅的中文原声片段。两段取自原片混合音轨，保留原背景音乐及声效；未找到独立原声轨。

音乐从原客户端源文件解码并整体降低音量以避免满幅失真。原作录屏静帧制作的素材预览仅用于核对，不代表本游戏实时画面或实际验收结果。此前战前九句改编方案未采用。

源文件编号、原包偏移及校验摘要见项目文档 Docs/Design/Endings20261110/SourceManifest.md。
